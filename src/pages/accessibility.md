Choice in Hackney wants everyone to be able to use this website, including people who use screen readers, keyboard navigation, voice controls or browser magnification.

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA. We test the website with automated tools and manual keyboard and screen-reader checks.

## What you should be able to do

- Navigate the website using only a keyboard.
- Navigate by headings and landmarks with a screen reader.
- Zoom and resize text without losing content or functionality.
- Understand links, buttons, form labels and error messages.
- Use the website with reduced-motion settings enabled.

## Alternative formats and communication support

If you need information in large print, audio, Easy Read, a printed copy or another language, please [contact us](/contact). Tell us which format or communication method works best for you.

## Reporting an accessibility problem

If any part of this website is difficult to use, please [contact Choice in Hackney](/contact). Include the page address and a brief description of the problem if you can. We will investigate it and explain how we plan to resolve it.

## Reviewing this statement

We review this statement whenever the website changes materially and after accessibility testing. This statement was last reviewed on 14 August 2026.
